COMP.CE.250 personal repository for introductory exercises

[**Course material in Moodle**](https://moodle.tuni.fi/course/view.php?id=42720)

New material is added by the staff periodically to the [template repository](https://course-gitlab.tuni.fi/compce250-spring-2025/student_template_project)\
To merge the changes to your repo:
```
git remote add course_upstream https://course-gitlab.tuni.fi/compce250-spring-2025/student_template_project.git
git fetch course_upstream
git merge course_upstream/main
```
